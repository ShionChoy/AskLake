# 生产治理

AskLake 的治理边界不是结果返回后的装饰性脱敏，而是位于认证、提示词构造、SQL/图查询执行
和审计记录之间的强制执行层。数据集策略位于 `datasets/imdb/governance.yaml`，认证凭据与数据
策略分离，存放在不提交版本库的 `auth.yaml`。

## 决策模型

策略采用默认拒绝。一次请求只有同时满足以下条件才会执行：

1. 凭据有效，或策略明确允许匿名角色；
2. 角色允许请求的操作：`ask`、`raw_sql`、`graph` 或 `export`；
3. 请求只引用该角色允许的数据表、字段或图关系；
4. SQL 通过 AST 只读和复杂度校验；
5. 请求满足行过滤、结果数量、内容和来源引用约束。

`public` 只用于匿名自然语言和图查询；`analyst` 可执行有界原始 SQL；`steward` 才拥有导出
能力。当前 API 没有批量导出端点，因此 `export` 是供后续受控工作流检查的显式能力，不会
因为角色存在而自动开放下载。

## 数据标签

数据标签与角色分开定义：

| 维度 | IMDb 实例 | 执行含义 |
|---|---|---|
| `confidentiality` | `public_source` | 来源公开，但不推导传播权限 |
| `license` | `imdb_noncommercial` | 返回许可提示，不提供公共批量导出 |
| `privacy` | `public_personal` | 人物年份对匿名角色遮罩 |
| `integrity` | `source_fact` / `llm_inferred` | 推断关系必须带来源并明确标记 |
| `content` | `adult_flag` | 成人影片不进入匿名角色的数据视图 |

热门度只属于答案质量和排序规则，不是安全等级，也不决定用户能否访问一部电影。

## SQL 强制执行

原始 SQL 和模型生成 SQL 使用相同的解析边界：

- 只接受一条 `SELECT` 或集合查询；
- 拒绝 DDL/DML、`COPY`、`PRAGMA`、`EXPLAIN` 和多语句；
- 拒绝 schema/catalog 限定名，阻止 `main.table` 或其他角色 schema 绕过；
- 拒绝外部文件、网络、环境变量和秘密读取函数；
- 拒绝未授权表、交叉连接、无连接条件 JOIN 和超过配置上限的复杂查询；
- 将每个物理表 AST 节点重写为 `rls_<role>` 视图；
- 在最外层追加不可绕过的返回行数上限。

角色视图启动时统一重建。列遮罩在视图内将原值转换为类型一致的 `NULL`，所以 SQL 别名、
表达式或结果列改名无法恢复原值。行策略或列配置无法绑定时，服务启动失败，不会回退到
无过滤视图。

## LLM 与图边界

发送给外部 LLM 的语义层按角色重新生成：被拒绝或遮罩的字段、相关 synonym、few-shot 和
真实值索引不会进入提示词。模型输出仍需经过完整 SQL 策略，提示词约束不作为安全边界。

图查询先按角色过滤关系、检查必须存在的来源并应用数量上限，再将事实交给答案生成模型。
`HAS_THEME` 和 `SET_IN` 被标记为 `llm_inferred`；IMDb 结构化关系保持 `source_fact`。

## 凭据配置

生成至少 256 bit 的随机访问令牌，将令牌本身交给用户，只在服务器保存 SHA-256 摘要：

```bash
openssl rand -hex 32
uv run python -m engine.auth.static_token
cp auth.example.yaml auth.yaml
```

把摘要、稳定用户标识和角色写入 `auth.yaml`。版本 2 配置拒绝明文 token。缺少凭据时是否
允许匿名访问由 `allow_anonymous` 决定；一旦客户端发送了无效凭据，API 始终返回 401。

静态 token 适用于本机部署或身份感知网关之后的服务。面向多租户互联网时，应通过
`Authenticator` 端口替换成 OIDC/JWT 验证，并在网关实现吊销、轮换、MFA 和速率限制。

## 审计

`ASKLAKE_AUDIT_PATH` 指向轮转 JSONL 文件。每条记录包含 UTC 时间、事件 ID、请求 ID、主体、
角色、操作、决策、原因代码和结果行数。自然语言问题与 SQL 默认只记录 SHA-256 和长度，
避免审计文件成为查询内容的副本。文件及轮转副本使用 `0600` 权限。

生产环境应将这些事件转发到不可变的外部审计系统，并对保留期限、访问告警和时钟同步进行
平台级配置。若本地审计路径在启动时不可创建，服务会直接启动失败。
